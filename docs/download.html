Free, no ads, no subscriptions. The Windows, macOS and AppImage builds update themselves after the first install.

Windows 10 and 11, x64. Not code-signed yet: if SmartScreen warns on first launch, click More info → Run anyway.

macOS your system

Disk image (.dmg)GitHub

macOS 12 or later, Apple Silicon and Intel. Signed with a Developer ID and notarized by Apple. Open it and drag Canopus to Applications.

Linux your system

AppImage or .debGitHub

x64, any distribution: chmod +x the AppImage and run it. Finds the chat logs of EVE under Steam's Proton or Wine.

iPhone & iPad your system

Canopus for EVE OnlineApp Store

A separate mobile app, iOS / iPadOS 26.5 or later. Characters, fits, market, industry, PI and the map.

After installing

  1. Log in with EVE SSO (bottom left). CCP's login page opens in your own browser; Canopus never sees your password.
  2. Settings → Language switches the interface and item names between English and Russian.
  3. For intel, run EVE windowed or borderless, copy Local with Ctrl+A, Ctrl+C and choose your intel channels.

On first start Canopus downloads CCP's static game data (about 100 MB) and builds a local database; it updates it when CCP publishes a new build.

Verifying a download

Every release lists the SHA-256 checksum of each file in its notes and in SHA256SUMS.txt, with a VirusTotal link for each. Windows and Linux builds are made by GitHub Actions from the public source. All files: releases on GitHub.
