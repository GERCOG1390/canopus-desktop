FAQ

Questions and answers

Is Canopus allowed by CCP? Can I be banned?

Canopus only uses official and player-visible data: CCP’s ESI and static game data, the chat and game logs the client writes to your Documents folder, and what you copy to the clipboard yourself. It never reads the game client’s memory and never automates input — the same approach as Pyfa or RIFT.

The multi-client previews show client windows the way the operating system’s window switcher does and only bring a window to the front; no keys or clicks are sent to the game. CCP publishes no list of approved tools, so as with any third-party tool you use it at your own risk.

Is it really free?

Yes: no ads, no subscriptions, no paid features. If you like Canopus you can send ISK to the author in game — completely voluntary.

Windows says “Windows protected your PC”. Is it safe?

The Windows builds are not code-signed yet, so SmartScreen warns on first launch: click More info → Run anyway.

Every release lists the SHA-256 checksum of each file with a VirusTotal link, and the Windows and Linux builds are made by GitHub Actions from the public source, so anyone can see how they were built.

Is logging in with my EVE account safe?

Canopus uses CCP’s own EVE SSO. The login page opens in your own browser, where you can check the login.eveonline.com address; Canopus never sees the page or your password.

Tokens are stored encrypted (Windows DPAPI, the macOS Keychain or the Linux keyring) and never leave your computer. Each permission and why it is needed is listed in the README; in-game actions and corporation data are asked for only when you turn them on.

Does Canopus send my data anywhere?

Nothing is sent to the developer. Canopus talks to CCP and the public EVE services it shows data from. See Privacy for the full list.

How does it update?

The Windows, macOS and AppImage builds check GitHub for new versions, download them in the background, verify them by SHA-256 and install on restart. This can be turned off in Settings → Updates. The .deb is updated from the release page.

How accurate is the fitting tool compared to Pyfa?

The engine was checked against Pyfa 2.69.3 on 44 fits with no differences. You can import all your Pyfa fits at once: several EFT fits or Pyfa’s XML file, mutated modules included.

How do I set up intel?

Run EVE windowed or borderless. Copy Local with Ctrl+A, Ctrl+C (Cmd on a Mac) and Canopus checks everyone automatically. For intel channels, pick them in Intel → Settings; the channels must be open in the game so the client writes their logs.

Does it work on Linux with Proton or Wine?

Yes. Canopus finds the chat logs of EVE running under Steam’s Proton or Wine automatically; for another location set the folder in Intel → Settings.

Which languages?

English and Russian — the interface and item names. Switch in Settings → Language.

Why does the first start take a while?

On first start Canopus downloads CCP’s static game data and builds a local database (about 100 MB). It does this again only when CCP publishes a new build.

Is there a phone version?

Yes, a separate app for iPhone and iPad: Canopus for EVE Online on the App Store. It is a different app from the desktop one.

I found a bug or a wrong number.

Report it in Issues — also from Settings → Help and feedback in the app. Questions and ideas go to Discussions.
